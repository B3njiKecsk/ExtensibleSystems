# Build
To run, execute [PvZExtended.exe](PvZExtended.exe)

## Build specific notes
- Currently this just plays out the first 20 levels of Adventure, being the 10 day and night levels. 
- Instead of a proper Death or Win screen, the game will close when reaching a win/lose conditions.
- While the almanac is given on level 2-5, it is not accessible in this current build.

## Debug keys
There are some debug tools to help the testing process:
- Pressing 8 on the keyboard will summon a falling sun onto the tile that will be clicked next
- Pressing 6, then clicking anywhere on the board, will summon the next wave of zombies immediately
- Pressing 9, then clicking anywhere on the board, will show the reward screen, where one can skip to the next level
- Pressing 7 will summon some (currently useless) coins onto the tile that will be clicked next.
